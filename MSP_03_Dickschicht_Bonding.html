Dickschicht Al₂O₃ y el proceso aditivo

Dickschicht = proceso aditivo (se deposita solo donde se necesita, vía serigrafía) — contraste directo con Leiterplatte (sustractivo). Sustrato: Al₂O₃ — barato, no tóxico, resiste 850°C, baja dilatación, buen aislante con conductividad térmica aceptable.

Rakel (racleta)

Poliuretano, dureza 65-80 Shore típica. Regla: sustrato duro → rakel dura. Se usa tirando, nunca empujando (daña el sieb). Presión constante durante todo el trazo. A menor ángulo, menos pasta pasa.

Pastas — 3 componentes base

Polvo de vidrio + disolvente/humectante + aglutinante orgánico. En el Praktikum: Leiterbahnpaste = Ag/Pd (conductora); Widerstandspaste = Pb + RuO₂ (resistiva, 10Ω/sq a 10MΩ/sq). Cocción (Einbrennen): ~125-150°C (secado) → ~850°C (glasura).

⚠️ Fórmula de Flächenwiderstand — el punto de confusión conocido

Relación fundamental: R = R_F · (L/W). Para despejar R_F a partir de una R medida: R_F = R / (L/W) — se DIVIDE, nunca se multiplica.

👉 El error típico (confirmado en tu propio protocolo, ver abajo) es multiplicar R_F = 10×(L/W) en vez de dividir R entre (L/W).

Bonding Historia y tipos de unión

1950: wire bonding manual con hilo de Au. Años 60-70: máquinas automatizadas (Au sigue dominando). 90-2000: cambio a Cu (más barato). 2010-hoy: Cu es el estándar industrial.

Thermokompressionsschweißen: alta temperatura (~300°C) + presión simultánea. Fuerza de unión ~0,147-0,245 N. Desventaja: presiones altas pueden dañar la subestructura.
Ultraschallschweißen: fuerza + energía ultrasónica, puede hacerse a temperatura ambiente. Ventaja: menos estrés/daño en los componentes.
Thermosonisches Verbinden: presión + calor + ultrasonido. Proceso más laborioso, pero conexión muy duradera (unión metalúrgica).

Anodisches Bonden (Waferbonden)

Campo eléctrico + temperatura sobre intercapa de vidrio Pyrex: los Na⁺ del vidrio migran al cátodo, el O restante forma enlace covalente Si-O-Si con ambas obleas. Aplicación típica: cámaras de referencia de presión (sensores de presión).

📋 Práctica — Dickschicht

  1. Impresión de pistas conductoras (Ag): Probedruck sobre lámina antes del sustrato real.
  2. Medición Vormessung (pasta húmeda) de anchuras vs. máscara.
  3. Cocción: Leiterbahnen 125°C→850°C; Widerstände 150°C→850°C.
  4. Nachmessung (post-cocción) + resistencia de cada pista (multímetro).
  5. Repetir con pasta resistiva (Pb+RuO₂), alineando con marcas de justaje.
  6. Medir L/W y R de 11 resistencias → calcular Flächenwiderstand.
  7. Comparación térmica resistor discreto vs. Dickschicht (curva P-T, 2-28V).
