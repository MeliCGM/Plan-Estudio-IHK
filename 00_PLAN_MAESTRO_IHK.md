# 🎯 PLAN MAESTRO: Umschulung Mikrotechnologie (IHK)

Este plan está diseñado para preparar a la Dra. Holmquist antes de iniciar el Umschulung en agosto de 2026. El enfoque es doble: **Conceptos Técnicos (PhD Química)** + **Alemán Técnico (IHK)**.

## 📅 Calendario de Preparación

### Abril: Módulo 1 - Fundamentos (TQ1 / TQ2)
*   [x] Silizium und Dotierung (Silicio y Dopaje)
*   [ ] Elektrotechnik Grundlagen (Leyes de Ohm, Kirchhoff)
*   [ ] Elektronische Bauelemente (Diodos, Transistores MOSFET)
*   [ ] Chemie Grundlagen für IHK (Ácidos, Bases, Seguridad)

*   [ ] Fotolithografie (Proceso completo en alemán)

### Julio: Módulo 4 - Mecánica y Automatización (TQ4 / TQ6)
*   [ ] Pneumatik (Válvulas, actuadores neumáticos)
